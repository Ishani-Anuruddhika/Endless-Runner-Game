# CubeRush – Endless Runner

CubeRush is a simple 3D endless runner game developed using Unity.

The player continuously moves forward and must avoid randomly spawned obstacles while trying to achieve the highest possible score.

## Game Objective

The objective is to survive as long as possible by avoiding obstacles.

The player has **3 lives**.

* Collision with an obstacle removes 1 life.
* Successfully avoiding an obstacle increases the score by 1.
* When all 3 lives are lost, the game ends.
* The player can restart the game using the Restart button.

##  Controls

| Action     | Control         |
| ---------- | --------------- |
| Move Left  | A / Left Arrow  |
| Move Right | D / Right Arrow |


##  Features

* Continuous forward movement
* Left/right player movement
* Random obstacle spawning
* Multiple obstacle lanes
* Collision detection
* 3-life system
* Score system
* Dodge-based scoring

##  Technologies

* Unity
* C#

##  How to Play

1. Start the game.
2. The player automatically moves forward.
3. Use A/D or Left/Right Arrow keys to change lanes.
4. Avoid incoming obstacles.
5. Earn points by successfully dodging obstacles.
6. The game ends when all 3 lives are lost.
